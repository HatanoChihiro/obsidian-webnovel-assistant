## 快速开始

### 安装方法

#### 从 Obsidian 社区插件市场安装（推荐）
1. 打开 **设置 → 第三方插件 → 浏览**
2. 搜索 **"WebNovel Assistant"**
3. 点击 **安装**，然后 **启用**

#### 使用 BRAT
1. 安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件
2. 在 BRAT 设置中添加此仓库：`HatanoChihiro/obsidian-webnovel-assistant`
3. 启用插件

#### 手动安装
1. 从 [Releases](https://github.com/HatanoChihiro/obsidian-webnovel-assistant/releases) 下载最新版本的 `main.js` 和 `manifest.json`以及 `styles.css`
2. 在 Obsidian 库中创建文件夹：`.obsidian/plugins/web-novel-assistant/`
3. 将下载的文件放入该文件夹
4. 重启 Obsidian，在设置 → 第三方插件中启用

> ⚠️ **数据备份提醒**：桌面端若只需保留历史字数与专注统计，可在 **设置 → WebNovel Assistant → 数据输出 → 历史数据备份** 中导出，重装后再从同一位置恢复；该备份不包含插件设置和便签。若还需保留设置或未另存为 Markdown 文件的便签，或正在使用移动端，仍建议正常关闭 Obsidian 后备份 `.obsidian/plugins/web-novel-assistant/` 下的完整 `data.json`。

### 首次使用

1. 打开任意 Markdown 文件
2. 状态栏会显示当前文件的字数统计
3. 点击状态栏可以设置目标字数

## 核心功能

### 工作区设置

#### 功能说明
- **扫描与作品识别边界**：工作区是插件扫描文件和识别作品的上层边界，不是单部作品目录。正常使用建议填写 `小说` 这类包含多部作品的顶层分类目录；插件会递归识别其下的分类、作品和卷目录。
- **默认落点**：第一个工作区决定创作主页的位置，以及新建/导入作品的默认父目录。例如工作区为 `小说` 时，新作品会创建为 `小说/作品名`。不要填写具体作品或卷目录，否则主页和新作品会落入作品内部；启用主页初始化时，其直接子目录还可能被当作作品补建作品信息。
- **影响范围**：
  - ✅ 作品根目录识别，以及工作台、章节一览和沉浸模式中的作品上下文（包括依赖该上下文的伏笔与时间线）
  - ✅ 创作主页的作品列表与总字数，以及新建/导入作品的位置
  - ✅ 章节字数、目标、写作增量与历史，以及文件浏览器字数缓存
  - ✅ 设定缓存、编辑器高亮与关系图谱
  - ✅ 章节排序、文件事件处理和排版的适用范围
- **范围外与留空**：工作区外文件仍会显示基础字数，但不参与写作增量、历史或目标。留空则作用于全库，扫描范围也会更广。

#### 使用方法
1. 打开插件设置
2. 找到 **工作区文件夹**
3. 输入顶层分类目录（如 `小说`），不要输入具体作品或卷目录
4. 多个顶层分类可用逗号分隔（如 `小说, 短篇`）；第一项是主页和新建/导入作品的默认落点
5. 留空则按全库范围处理

#### 使用场景
- 同一个库中有多个项目，只想让小说分类参与插件扫描和作品识别
- 避免笔记、日记等非小说内容影响统计
- 缩小扫描、监听和缓存范围

### 新增和导入作品

请先设置工作区文件夹。推荐直接使用文件浏览器中的右键入口，无需开启创作主页；新增或导入的作品默认放在第一项工作区文件夹下。

#### 从文件浏览器新增作品（推荐）
1. 在文件浏览器中右键第一项工作区文件夹，选择 **新增作品**。
2. 在弹窗中填写作品名称、简介、类型、总字数目标
3. 点击「创建」，自动生成作品文件夹和作品信息文件

#### 从文件浏览器导入作品（推荐）
1. 在文件浏览器中右键第一项工作区文件夹，选择 **导入作品**。
2. 在弹窗中选择需要导入的单本长篇 txt 或 md 格式小说文件。
3. 系统将依据默认或配置的 **自定义章节命名规则** 识别卷与章节，预览切分结果，再批量生成 Markdown 文档并整理到对应卷目录。
4. > 💡 **小提示**：如果您的原作品为 Word 格式（`.docx` / `.doc`），建议先使用 Pandoc 或其他工具将其另存/转换为 `.md` 文件再进行导入，以保留原有的文本格式。

#### 创作主页入口（可选）
开启创作主页后，也可使用主页中的 **新增作品** 和 **导入作品** 按钮完成相同操作。不使用创作主页的用户只需使用文件浏览器右键入口。

### 智能章节排序

#### 功能说明
- **自动排序**：按章节编号自动排序
- **多种格式**：默认支持阿拉伯数字、中文数字
- **文件夹排序**：文件夹（如"第1卷"）也能参与排序，同编号文件夹排在文件前
- **自定义规则**：支持自定义正则表达式
- **实时生效**：创建/重命名文件后自动排序
- **拖拽排序**：非章节文件和章节区块可拖拽调整顺序，章节区块整体移动

> **💡 拖拽排序**：
> 智能章节排序内置了拖拽排序功能：
> - **章节区块**：所有章节文件作为一个整体区块，可拖拽移动位置（如拖到非章节文件下方）
> - **非章节文件**：可拖拽调整顺序，穿插在章节区块上下
> - 章节区块内部始终按编号排序，不可单独拖拽某章

#### 使用方法

##### 启用功能
1. 打开插件设置
2. 启用 **智能章节排序**
3. 文件浏览器中的章节会自动排序

##### 支持的格式
- 阿拉伯数字：`第1章`、`第01章`、`Chapter 1`
- 中文数字：`第一章`、`第二十三章`、`第一百章`、`第九百九十九章`
- 具名章节：`大纲`、`番外`、`楔子`（需在规则中配置）
- 纯数字：`1`、`01`、`001`
- 自定义规则

##### 自定义规则

1. 打开插件设置 -> **智能排序**。
2. 找到 **排序规则配置**。
3. 点击 **+ 添加新规则**。
4. 输入规则名称和正则表达式。
5. **调整顺序**：使用规则左侧的 **▲/▼** 按钮调整优先级。
6. **启用/禁用**：每个规则都可以单独开关。

> **💡 正则规则核心原理**：
> - **有括号 `(\d+)` 的规则**：括号捕获编号，插件按编号排序。如 `第1章` → 编号1，`第2章` → 编号2。
> - **没有括号的规则**：不提取编号，视为"具名章节"，按文件名字典序排列。如 `前言`、`番外`。
> - **规则顺序决定位置**：先匹配到的规则分组排在上面。想把番外放在正文后面，就把番外规则放在编号规则下面。

##### 默认预设规则

插件在设置中预设了 5 个常用规则，前 3 个默认开启，你可以随时在设置中调整开启状态：

**规则 1：阿拉伯数字（第1章、第01章）**
```
名称：阿拉伯数字（第1章、第01章）
正则：^(?:第(\d+)[章节回卷部册篇]?|第?(\d+)[章节回卷部册篇])
启用：是
```
支持格式：`第1章`、`第01章`、`1章`、`第1节`、`第1回`、`第1卷`、`第1部`、`第1册`、`第1篇`

**规则 2：中文数字（第一章、第二章）**
```
名称：中文数字（第一章、第二章）
正则：^(?:第([零一二三四五六七八九十百千万壹贰叁肆伍陆柒捌玖拾佰仟萬〇]+)[章节回卷部册篇]?|第?([零一二三四五六七八九十百千万壹贰叁肆伍陆柒捌玖拾佰仟萬〇]+)[章节回卷部册篇])
启用：是
```
支持格式：`第一章`、`第二十三章`、`第一百章`、`第九百九十九章`（支持一到九百九十九）

**规则 3：纯数字及带标题（1、01、001 标题）**
```
名称：纯数字及带标题（1、01、001 标题）
正则：^(\d+)(?:[ \-].*)?$
启用：是
```
支持格式：`1`、`01`、`001 序章`（纯数字或空格/连字符后接标题的文件名，**不包含小数点**）

**规则 4：英文章节 (Chapter 1, Ch.1)**
```
名称：英文章节 (Chapter 1, Ch.1)
正则：^[Cc]h(?:apter)?\.?\s*(\d+)
启用：否
```
支持格式：`Chapter 1`、`Ch 01`、`ch.1`

**规则 5：全能括号 ( (1)、【30】 )**
```
名称：全能括号 ( (1)、【30】 )
正则：^[（\(【「{]([0-9零一二三四五六七八九十百千万]+)[）\)】」}]
启用：否
```
支持格式：`(1)`、`（一）`、`【30】`、`「一百」`、`{2}`

##### 自定义规则示例

除了默认规则，你还可以添加自己的规则：

**小数点章节**（如：1.1、1.2、2.1、2.2）
```
名称：小数点章节
正则：^(\d+\.\d+)
启用：是
```


**数字与小数混合排序**（如：1、1.5、2、2.1）

如果你希望纯数字和小数点章节严格按照数学大小混合穿插排序，必须**关闭默认的纯数字规则**，并只启用这一条“全包含”规则（将它们归为同一类，底层才能执行大小比较）：
```
名称：数字与小数混合排序
正则：^(\d+(?:\.\d+)?)(?:[ \-].*)?$
启用：是
```

**卷章节**（如：第一卷第一章）
```
名称：卷章节
正则：^第.+卷第?(\d+)[章节]?
启用：是
```

**具名章节 — 多个名称合并为一条规则**（如：前言、番外、后记）

一条规则就能匹配多种文件名，用 `|` 分隔即可，无需逐个添加：
```
名称：特殊章节（前言/番外/后记等）
正则：^(前言|序章|楔子|引子|番外|外传|后记|尾声|附录)
启用：是
```
这条规则没有括号捕获编号，所以匹配的文件都按文件名字典序排列。你可以通过调整规则顺序来控制位置——放在编号规则上方则排在正文前面，放在下方则排在后面。

**带编号的具名章节**（如：番外1、番外2）

如果具名章节本身带编号，加上括号捕获编号即可按数字排序：
```
名称：番外系列
正则：^番外(\d+)
启用：是
```
这样 `番外1` → 编号1，`番外2` → 编号2，自动按顺序排列。

> **提示**：
> - 正则表达式中的 `(\d+)` 或 `(\d+\.\d+)` 用于捕获章节编号
> - 规则的顺序决定了排序的优先级（上面的规则优先）
> - 可以同时启用多个规则，插件会按顺序匹配
> - `|` 表示"或"，可以一条规则匹配多种文件名

> **⚠️ 重要提醒**：
> 如果同时启用了**数字规则**（如 `^(\d+)(?:[ \-].*)?$`）和**小数点规则**（如 `^(\d+\.\d+)`），建议将小数点规则放在数字规则**上方**。虽然新版默认数字规则已经排除了对小数点的误判，但对于自定义数字规则，顺序依然很重要。
>
> **正确顺序**：
> 1. 小数点章节 `^(\d+\.\d+)` ✅
> 2. 纯数字 `^(\d+)(?:[ \-].*)?$` ✅

### 严格章节模式

#### 功能说明
- **精准过滤**：章节列表、写作工作台及所有字数相关功能只识别符合“章节命名规则”的文档。
- **排除干扰**：开启后，大纲、设定、草稿等非章节文档不会进入章节视图，也不会计入每日字数进度或显示目标和字数提醒。
- **灵活性**：如果需要识别特定的具名章节（如“番外”），只需在排序规则中添加相应的匹配规则即可。
- **可设置例外目录**：可将指定目录设为例外，使其中所有文档按章节处理。

#### 使用方法
1. 打开插件设置 → **通用**。
2. 启用 **启用严格章节模式**。
3. 确保章节名称符合 **章节命名规则配置** 中的任一启用规则，或将需要整体识别的目录加入例外。

### 字数统计

#### 功能说明
- **精确统计中文字数**：准确识别中文、英文、数字
- **实时更新**：编辑时自动更新字数
- **净增字数**：显示本次会话新增的字数
- **状态栏显示**：在 Obsidian 底部状态栏显示
- **严格章节模式**：限制字数相关功能仅在符合命名规则的章节中生效（详见 [严格章节模式](#严格章节模式)）
- **字数实时提醒**：在编辑器左侧实时显示累计字数提醒（详见 [字数实时提醒](#字数实时提醒)）

#### 使用方法
1. 打开任意 Markdown 文件
2. 状态栏自动显示字数：`1,234 字 | 净增: +56 字`
3. 点击状态栏可以快速设置目标

#### 相关设置
- **工作区文件夹**：限制统计范围（详见 [工作区设置](#工作区设置)）
- **非工作区文件**：不在工作区范围内的文件仍会在状态栏显示基本字数（不含追踪状态和净增字数）

- ✅ 统计：中文字符、英文单词、数字
- ❌ 不统计：Markdown 语法、代码块、注释、YAML frontmatter

#### 统计稳定性与防跳变 [HOT]
为了解决 Obsidian 插件中常见的”字数统计激增/减少”问题，本插件采用了一套多重校验架构：
- **实时同步**：编辑器内的改动会即时同步到内存缓存。
- **文件基准同步**：当文件被自动保存（触发 modify 事件）时，插件会通过时间戳校验来对比当前缓存与磁盘内容的差异，确保增量计算是基于同一个基准点的。
- **冷启动保护**：在插件加载和索引构建期间，所有的文件改动都会被实时捕捉以更新缓存基准，防止在布局就绪后产生巨大的虚假增量。

#### 字数统计模式

插件提供三种字数统计算法，适配不同创作场景：

| 模式 | 规则 | 适用场景 |
|------|------|---------|
| **网文模式** | 所有非空白字符均算1个字（含标点） | 起点中文网、晋江文学城等网文平台的字数计算规则 |
| **标准模式**（默认） | 中文逐字 + 英文按词 + 全角标点算字，半角标点不计 | Word、WPS 等文档工具的常用字数方案 |
| **原生模式** | 中文逐字 + 英文按词，忽略所有标点 | 接近 Obsidian 内置字数统计 |

##### 切换方法
1. 打开插件设置 → **字数统计**
2. 找到 **字数统计模式**
3. 从下拉菜单中选择所需模式
4. 切换后自动全库重新计算字数

> **💡 提示**：不同模式下同一篇文档的字数可能差异较大，这是正常现象。选择与你投稿平台一致的统计模式即可。

#### 选中字数统计悬浮窗

在 **设置 → 字数统计** 中开启 **启用选中字数统计悬浮窗** 后，在编辑器中选中两个或更多字符，会在光标附近显示按当前字数统计模式计算的选区字数。取消选择后提示会自动消失。

#### 标记不统计字数

如果某篇章节暂时不应计入统计（例如大纲、废稿或备用版本），可以单独将其排除，而无需开启严格章节模式。

##### 操作方法

- **桌面端**：在文件浏览器或已打开文档中右键目标文件，选择 **标记不统计字数**。
- **手机/平板**：打开目标文件的菜单，在 **网文助手** 子菜单中选择 **标记不统计字数**。
- **写作工作台**：在章节卡片上右键，选择 **标记不统计字数**；卡片会显示 **不计字数** 状态。

标记后，该文件不会计入作品总字数、每日写作统计及其他依赖章节字数的功能。插件会在文档 frontmatter 中写入 `exclude-word-count: true`，不会修改正文内容。

如需恢复，在相同位置选择 **取消排除字数统计** 即可；插件会重新计算该文件并刷新相关统计。

### 写作工作台

#### 功能说明
写作工作台是由原“章节一览”全新升级而来的综合性写作管理中心，集成了 6 个主要的选项卡面板：

各面板标题后的链接可快速跳转到对应功能的详细说明。

1. **全章节面板**（详见 [智能章节排序](#智能章节排序)、[智能创建章节](#智能创建章节)、[章节模板](#章节模板)、[合并章节](#合并章节)）：
   - 快速创建章节，修改章节名称与摘要。
   - 支持**手动拖拽排序**（若文件名包含章节序号，拖拽后自动按新顺序自动重命名后续文件）。
   - 卡片底部的徽章会自动显示当前章节中出现的**设定**与**伏笔**，点击即可快速预览。
   - **支持多章节模板配置**：可在设置中配置多个模板，创建下一章时按需选择模板。
2. **时间轴面板**（详见 [时间线管理](#时间线管理)）：
   - 以竖向时间流展示小说事件，支持把章节卡片拖拽到特定时间节点绑定事件，支持拖拽事件卡片重新排序。
   - 底部内置未关联章节悬浮窗，浮动关联连线高亮，不再遮挡时间轴。
3. **设定面板**（详见 [设定速查](#设定速查)、[设定图谱](#设定图谱)、[设定一览](#设定一览)）：
   - 支持**表格视图**、**卡片视图**与**全量设定图谱视图**快速切换。
   - 自动统计出场总次数和出场章节，支持图谱节点双击跳转到对应 Markdown 设定文档。
4. **伏笔看板面板**（详见 [伏笔管理](#伏笔管理)）：
   - 全新专用的伏笔集中展示与管理视图。
   - 按照 `待回收`（包含未回收与阶段推进）、`已回收`、`已废弃` 三大分类栏目归组展示伏笔卡片，支持分类折叠。
   - 提供顶栏关键词搜索框，可实时按标题、描述或标签过滤伏笔卡片。
   - 点击伏笔卡片可精准跳转并闪烁高亮定位到对应源笔记的具体行。
5. **任务看板面板**（详见 [限时任务追踪](#限时任务追踪)）：
   - 将限时任务集中在工作台中以卡片网格显示，支持直接在工作台新建限时任务。
   - 针对未完成的进行中任务提供**放弃任务**按钮及二次确认，放弃后状态标记为 `已放弃` (`abandoned`) 并保留历史字数记录。
6. **便签管理面板**（详见 [悬浮便签](#悬浮便签)）：
   - 统一集中管理全库所有悬浮与沉浸便签，支持新建、编辑、修改主题与删除便签，与桌面悬浮便签与沉浸便签双向实时同步。

- **分屏导航**：从工作台打开章节、设定、时间线或伏笔时会优先复用未锁定的编辑器分屏，并避开已锁定标签，方便对照编辑。
- **全文筛选**：全章节面板可按章节标题、摘要和正文筛选；设定面板可按标题、别名和正文筛选；伏笔看板可按标题、原文、标签和回收说明筛选。可点击输入框右侧清除按钮、按 Esc，或执行 **工作台：清空搜索筛选框** 恢复完整列表。

#### 使用方法

##### 打开写作工作台
1. 命令面板（Ctrl/Cmd + P）输入 `打开写作工作台面板`
2. 或点击左侧 Ribbon 菜单中的工作台图标
3. 打开任意章节文件后，工作台会自动识别当前作品并展示对应内容。

### 沉浸写作模式

#### 功能说明
- **全屏专注**: 进入全屏创作环境，隐藏 Obsidian 侧边栏、状态栏、顶栏及 Ribbon 菜单等所有干扰元素。
- **右上角半隐藏退出按钮**: 右上角特意设计了退出沉浸模式按钮，在进入沉浸模式时会自动隐藏，鼠标移上去即可看到并点击退出（亦可通过命令面板退出），是为了最大化沉浸感而做的特意设计。
- **动态仪表盘**: 顶部实时显示小说标题、专注/摸鱼时长、今日净增字数及目标进度。
- **打字机居中滚动与行淡化**: 支持打字机居中滚动（Typewriter Scroll）与上下文行淡化（Line Dimming），可在中央状态栏开关一键切换，专注当前行创作。
- **插槽化布局**: 自由分配辅助面板到主编辑区的上下左右四个区域，无分配的面板区域自动贴边，主编辑区最大化。
- **参考文档**: 在章节上左击开启文档到主编辑区，右击到右侧参考区。

#### 使用方法
- **进入沉浸模式**：打开任意小说章节（Markdown 文件），通过命令面板（Ctrl/Cmd + P）输入 `进入/退出全屏沉浸写作模式`，或在普通模式下点击左侧 Ribbon 菜单图标。
- **退出沉浸模式**：鼠标移动至屏幕右上角，点击浮现的退出按钮；或通过命令面板（Ctrl/Cmd + P）输入 `进入/退出全屏沉浸写作模式` 退出。

#### 相关设置
- **打字机居中滚动**: 开启后光标所在行保持在屏幕中央垂直居中。
- **上下文行淡化**: 开启后非聚焦行淡化显示，提升专注度。
- **中心偏移量与未聚焦淡化不透明度**：可微调当前行的垂直位置及周围文本的淡化强度。
- **插槽布局**: 在设置页面的沉浸模式选项卡中，通过可视化布局器自由拖配各面板（章节列表、伏笔、时间线、便签、参考文档、章节一览、设定一览）到上下左右四个区域。
- **自动隐藏属性面板**: 开启后在沉浸模式下自动隐藏 Markdown 文件顶部的属性面板区域。
- **顶部仪表盘数据开关**：可分别显示或隐藏总计时间、专注时间、摸鱼时间、章节目标、今日目标、任务目标和本场净增。
- **便签文字大小与排版**: 便签的字体大小与显示样式现已统一由 **创作辅助** 设置中的相关选项集中管理。

### 智能创建章节

#### 功能说明
- 提供工作台 **新增章节** 和命令面板 **自动创建下一章 (智能递增)** 两种入口。
- 优先按照启用的自定义章节命名规则识别编号，同时支持常见的阿拉伯数字、中文数字及小数点章节格式。
- 两种入口均与 [章节模板](#章节模板) 联动：无有效模板时创建空白章节，一个模板时自动应用，多个模板时可选择模板或空白章节。

#### 从工作台新增章节
1. 打开写作工作台并进入 **全章节面板**，点击右上角 **+ 新增章节**。
2. 插件会根据当前作品最新章节目录中的已有文件建议下一章名称；可在弹窗中修改完整章节名，无需输入 `.md` 后缀。
3. 确认名称后，按提示选择章节模板。新文件会创建在当前作品的最新章节目录中，工作台随后自动刷新并保持在当前界面。

#### 使用命令面板自动创建下一章
1. 打开一个文件名包含可识别章节编号的现有章节。
2. 打开命令面板（Ctrl/Cmd + P），执行 **自动创建下一章 (智能递增)**；也可在 **设置 → 快捷键** 中为该命令分配快捷键。
3. 插件会保留当前章节的编号结构并递增编号，在同一目录生成下一章；原章节的具体标题不会被带入新文件名。
4. 如果计算出的目标文件已经存在，插件会直接打开该文件，不会重复创建；否则会应用所选模板、创建文件并自动打开。

> **无法创建时**：如果当前文件名无法被自定义规则或默认编号格式识别，插件会停止创建并显示提示。请先调整文件名，或在章节命名规则中添加对应格式。

1. 打开命令面板（Ctrl/Cmd + P），执行 **打开便签列表**，便签列表会固定显示在 Obsidian 侧面板中；桌面端和移动端均可使用。
2. 点击侧面板顶部的 **+** 可新建空白便签；点击文件夹按钮可选择一个 Markdown 文件并将其作为关联便签打开。
3. 所有便签以卡片形式集中排列，可直接在卡片中编辑正文。开启 **便签自动保存** 后，修改会自动保存；关联文件的内容也会同步更新。
4. 点击卡片右上角 **×** 可关闭并移除该便签；存在需要保存的内容时会先弹出保存确认。
5. 便签列表、桌面悬浮便签、工作台便签面板与沉浸模式便签共享同一份数据，任一入口的修改都会同步到其他入口。移动端不支持桌面悬浮窗口时，可将便签列表作为主要管理入口。

##### 编辑便签
- **编辑模式**：点击铅笔图标
- **预览模式**：点击眼睛图标
- **更换主题**：点击调色板图标
- **固定位置**：点击图钉图标
- **同步文档**：点击刷新图标，从关联文档同步最新内容到便签（仅在便签关联了文档时显示）

##### 保存便签
- **保存到文件**：点击保存图标
- **关联文件**：如果便签来自文件，保存会更新原文件
- **新建文件**：如果是空白便签，会提示创建新文件

##### 关闭便签
- 点击关闭按钮（X）
- 如果有未保存的内容，会提示保存

> **注意**：
> - 便签支持**自动保存**（需在设置中开启），即使重启 Obsidian，只要未关闭的便签都会恢复。
> - 在沉浸模式下，便签以**网格卡片**形式排列在底部/顶部辅助面板中。

- **同步机制**: 正常模式下的悬浮便签与沉浸模式下的卡片视图共享同一份数据。你在任意一端做的修改，另一端都会实时响应。

#### 相关设置
- **便签主题**：6 种预设主题颜色，可自定义
- **闲置透明度**：悬浮便签背景透明度（0.1-1，默认 0.9）
- **便签自动保存**：开启后输入内容即时保存；关闭后仅在关闭有改动的便签时提示保存。
- **便签文本大小**：统一调整桌面悬浮便签、侧面板便签列表、工作台便签面板与沉浸模式便签中的正文字号；悬浮便签不再使用 `Ctrl/Cmd + 鼠标滚轮` 单独缩放。
- **显示/隐藏所有悬浮便签**：桌面端可从命令面板一键隐藏或恢复全部悬浮便签及其布局。

### 伏笔管理

#### 功能说明
- **标注伏笔**：标记需要后续回收或揭晓的伏笔。
- **阶段性回收**：支持伏笔在故事推进过程中的**多次阶段推进**（记录 `[阶段]` 进展说明）与**最终彻底回收**（记录 `[回收]` 章节），契合长篇小说伏笔逐步揭开的规律。
- **多章节关联**：一个伏笔可以在多个不同的章节中记录回收或阶段进展。
- **工作台伏笔看板**：在写作工作台中提供专用的伏笔看板，按 `待回收`（含未回收与阶段推进）、`已回收`、`已废弃` 归类并支持分类折叠与搜索。
- **标签分类**：使用标签灵活组织和筛选伏笔。
- **智能高亮定位**：点击伏笔卡片或条目可自动高亮跳转至对应源文档的具体行。

#### 使用方法

##### 标注伏笔
1. 选中需要标注的文字
2. 右键 → `标注为伏笔`
3. 或使用快捷键（需在设置中自定义）
4. 输入伏笔描述和标签
5. 点击保存

##### 查看与管理伏笔
- **方式一：通过工作台【伏笔看板】（推荐）**
  1. 打开写作工作台，切换到 **伏笔看板** 选项卡。
  2. 看板按照 `待回收`（未回收+阶段推进）、`已回收`、`已废弃` 三列/三大栏目直观展示。
  3. 可使用顶部搜索框实时检索特定伏笔。
- **方式二：通过侧边栏【伏笔面板】**
  1. 点击左侧 Ribbon 图标（书签图标）或命令面板 → `打开/关闭伏笔面板`
  2. 可按**状态**和**标签**筛选伏笔。

##### 回收与推进伏笔
- **阶段推进**：
  1. 在伏笔卡片或面板中选择 **阶段回收**。
  2. 输入本次阶段推进的说明与关联章节（例如“第十五章 揭露了主角的部分身线索”），该伏笔仍保持在 `待回收` 分类中，但会附带阶段推进日志。
- **彻底回收**：
  1. 选择 **彻底回收**。
  2. 选择完成最终回收的章节并提交，伏笔状态更新为 `已回收`。
- **在伏笔文件中回收**：
  1. 打开伏笔文件（默认名称：`伏笔.md`）
  2. 将光标放在伏笔条目上
  3. 命令面板 → `标记伏笔已回收`
  4. 选择回收章节

#### 相关设置
- **伏笔文件名**：默认 `伏笔`，可自定义
- **显示时间戳**：是否显示创建时间（默认启用）
- **默认标签**：预设常用标签（默认：人物、情节、世界观、道具、线索）

### 限时任务追踪

#### 功能说明
- **限时任务追踪**：追踪网文平台（起点、晋江等）的限时任务与连载打卡，适配多种创作场景。
- **工作台集成**：限时任务已全面集成至「写作工作台」的【任务看板】选项卡中，以直观的网格卡片形式集中管理，取消了原独立侧边栏面板。
- **自动计算**：创建时记录文件夹总字数快照，实时计算字数增量。
- **到期与自主放弃**：任务到期后自动更新状态；未达标的进行中任务支持在卡片上主动点击「放弃」按钮（含二次确认），状态转换为 `已放弃` (`abandoned`) 并保留历史字数记录。
- **期数递增**：支持同一文件夹多期任务，新增时期数自动递增。
- **进度可视化**：写作数据面板与创作主页显示任务进度条与截止时间提示。
- **达标提示**：字数达标时进度条变绿，截止时间处显示"已达标！"。
- **起始字数可编辑**：新增任务时可查看并手动修改起始字数，方便衔接上一期的完成进度。

#### 使用方法

##### 查看限时任务看板
1. 打开 **写作工作台**（左侧 Ribbon 菜单图标或命令 `打开写作工作台面板`）
2. 切换至顶部选项卡 **【任务看板】**
3. 看板以卡片网格形式清晰展示进行中、已完成、未达标及已放弃的任务进度

##### 新增限时任务
- 在【任务看板】顶部点击「+ 新增任务」按钮
- 或在文件树右键点击作品文件夹/文件 → **开启限时任务追踪**
- 在弹出的对话框中填写名称、期数、时间、目标字数后保存即可

##### 放弃未完成任务
- 在【任务看板】的进行中任务卡片下方，点击红底白字「放弃」按钮
- 在二次确认弹窗中点击确认，任务状态将记录为 `已放弃` (`abandoned`)

#### 相关设置
- **限时任务文件名**：默认 `限时任务`，可在设置中自定义（旧版默认名为 `榜单记录`，自动兼容）
- **沉浸模式限时任务进度**：是否在沉浸模式顶部状态栏显示限时任务进度（默认启用）

### 设定管理

设定管理统一覆盖正文中的设定速查、关系图谱和独立设定一览；三者共用同一套设定文件与缓存。

#### 设定速查

##### 功能说明
- **多级设定库**：设定文件夹支持任意层级的子目录，插件会自动扫描其中的 Markdown 文档
- **自动精准标注**：在分类文档中使用二级标题（`##`）创建设定词条，并在正文补充 `**别名**：xxx`。当你在小说正文敲出正名或别名时，系统自动打上虚线下划线
- **单文件词条**：如果设定文档中没有二级标题，插件会将文件名作为一个设定词条，适合按“一项设定一个文件”的方式组织资料
- **悬浮/点击速查**：桌面端鼠标悬停、移动端点按标注文字，都可弹出精准定位到该词条的小窗口，无需切出编辑页
- **右键"边写边建"**：在编辑器中直接划选一个新道具或角色的名字，右键点击"添加为新设定"，即可在弹窗中极速录入
- **别名支持**：在每个词条的正文中使用 `别名：xxx` 或 `Alias: xxx`；标签可加粗，支持中英文冒号。多个别名可用逗号、顿号、分号、斜杠或竖线分隔，并会映射到该词条

##### 使用方法

###### 配置设定文件夹
1. 打开插件设置 → **创作辅助**
2. 找到 **设定文件夹名称**
3. 输入存放设定文件的文件夹名称（默认"设定"）
4. 在每部作品的目录下创建该文件夹，将分类设定文档放入其中

###### 创建设定文档（字典大纲模式）
在设定文件夹下创建分类文档，使用 `## 二级标题` 作为词条正名：

```markdown
# 角色志

## 张三
主角，少年剑客。
**别名**：三哥、小张

## 李四
反派，阴险狡诈。
**别名**：四爷

## 王五
配角，忠诚的伙伴。
```

> **💡 提示**：
> - 每个二级标题（`##`）是一个独立词条，标题文本即正名
> - 包含二级标题时，一级标题（`#`）和三级标题（`###`）不会被单独当作词条
> - 如果整个文件没有二级标题，则文件名会作为唯一词条名；仍可在正文或 frontmatter 中填写别名
> - 设定文件可以放在设定目录的多级子文件夹中，便于按人物、地点、道具等继续细分
> - 别名必须写在所属二级标题的正文内，可用 `别名：xxx` 或 `Alias: xxx`（加粗可选）；多个别名可用逗号、顿号、分号、斜杠或竖线分隔

###### 使用设定速查
1. 在正文中输入角色名或别名（如"张三"或"三哥"）
2. 文字会自动出现虚线下划线
3. 鼠标悬停即可预览设定卡片内容，精准定位到对应词条

###### 重建设定缓存
当设定文件或章节已经存在、但设定高亮、工作台统计或关系图谱未及时更新时，可在 **命令面板（Ctrl/Cmd + P）→ `重建设定缓存`** 手动执行。该命令会重新扫描设定条目、批量刷新章节中的设定引用统计，并刷新编辑器高亮、工作台和关系图谱。

###### 右键添加新设定
1. 在编辑器中选中一个新名字（如"玄铁剑"）或直接点击命令/菜单
2. 右键 → **添加为新设定**
3. 在弹窗中填写设定名称、选择/输入分类文档、预设类型（支持预设下拉补全）、别名与详细描述
4. 支持在弹窗内直接可视化添加**设定关系**（可选择目标设定及输入描述关系，保存时自动落盘格式规范的 `### 关系` 语法）
5. 点击保存，设定自动格式化写入对应的分类 Markdown 文档

> **移动端**：设定名和别名仍会被识别并显示虚线下划线。开启“移动端开启设定悬浮/点击卡片”后可点按查看卡片；关闭该选项只会禁用卡片，以避免滑动误触。

##### 相关设置
- **设定文件夹名称**：默认 `设定`，可自定义

#### 设定图谱

##### 功能说明
- **自动关系解析**：一键生成角色之间的关系图，基于“设定速查”解析到的文中互相提及关系（虚线连接）。
- **显式关系定义**：在角色设定的 Markdown 文件中，使用 `### 关系` 或 `### Relations` 建立显式关系（实线连接）。格式支持无序列表，如 `- [目标人物]: 关系说明`。
- **自定义样式**：支持高度定制的外观（颜色、线条、虚线等），并可通过 CSS Snippets 进行深度魔改。
- **完整示例**：可直接复制并按需修改 [设定图谱 CSS 代码片段完整示例](LORE_GRAPH_CSS_EXAMPLE.css)，同时适用于独立图谱与工作台全量图谱。
- **动态交互**：支持双击跳转到角色文档，滚轮缩放，右键平移画布。悬停高亮关联节点和连线。

##### 使用方法

###### 开启设定图谱
1. 右键任意**设定文件夹内**的文档，在右键菜单中选择 **打开设定图谱**。
2. 插件会自动从当前文档所在的设定文件夹向外推断所属小说，加载全局人物并在右侧边栏打开图谱视图。

###### 定义显式关系
1. 在设定文档中（例如“人物设定.md”），找到你需要添加关系的角色标题（如 `## 主角`）。
2. 在该角色名下新建一个名为 `### 关系` 的三级标题。
3. 按照如下格式填写（加粗表示**关系名**，冒号后是目标角色名，多个角色用逗号或顿号分隔）：
```markdown
## 李雷
**别名**：小雷
**描述**：男主角

### 关系
- **青梅竹马**: 韩梅梅
- **宿敌**: 王明, 魏华
```
4. 设定图谱会解析 `**关系名称**: 目标名称` 并在图谱中以实线绘制箭头和标签。

##### 相关设置
- **悬浮卡片折叠子标题**：设定速查内容较长时，可让三级及以下子标题默认折叠，点击后展开。
- **自动关联提及**：开启后，图谱会根据设定正文中对其他正名或别名的提及自动生成关系；关闭后只显示 `### 关系` 中明确定义的关系。
- **启用跨文件图谱关联**：开启后读取整个设定文件夹并构建全局关系图；设定文件很多时可能增加计算开销。关闭后仅处理当前设定文档范围。

#### 设定一览

##### 功能说明
- **原样抽取卡片**：将设定看板中的全部卡片原样抽取为独立侧面板，直观展示各分类下的设定词条。
- **分类折叠分组**：各分类以可折叠标题栏分组排列，清晰展示各分类名称与包含的设定条目数，与章节一览的分卷网格体验高度统一。
- **就地编辑与保存**：点击卡片编辑图标可直接在卡片上展开编辑框进行实时修改，失焦或按 Esc 自动保存并同步至原设定文件。
- **正文高亮跳转**：点击设定卡片标题，自动在分屏中打开对应设定文档并在正文中精准定位高亮该词条。
- **沉浸模式组件**：支持作为沉浸写作模式的槽位组件使用，在沉浸写作时随时对照与编辑设定。

##### 使用方法
1. 命令面板（Ctrl/Cmd + P）输入 `打开设定一览`。
2. 或在插件设置中的沉浸模式可视化布局器中，将“设定一览”拖配至任意槽位。

### 章节一览（经典版）

#### 功能说明
- **侧边栏挂载**：原章节一览面板仍然可用，主要用于挂载在 Obsidian 的左右侧边栏中作为辅助视图，或作为**沉浸模式**的专用组件。
- **分卷分类支持**：支持识别小说中的分卷子目录。当存在分卷时，自动展示可折叠的分卷标题栏与分卷章节数统计，点击可折叠或展开对应分卷，与工作台全章节软木板保持一致。
- **状态与摘要**：支持标记章节状态（待写、大纲、草稿、修稿中、已完稿）和直接编辑章节摘要（保存到 frontmatter 的 synopsis 字段）。
- **字数统计**：每张卡片底部显示章节字数。

#### 使用方法

##### 打开章节一览
1. 命令面板（Ctrl/Cmd + P）输入 `章节一览`
2. 或在沉浸模式的插槽中分配"章节一览"

##### 编辑章节摘要
1. 点击卡片内容区域
2. 输入章节摘要
3. 按 Ctrl+Enter 或点击其他区域保存，按 Esc 取消

##### 切换章节状态
1. 点击卡片右上角的状态标签
2. 从弹出菜单中选择新状态

> **提示**：状态和摘要信息保存在每个章节文件的 YAML frontmatter 中（`status` 和 `synopsis` 字段）。

#### 功能说明
- **本地实时校对与隐私安全**：错词检测、近义词推荐、敏感词扫描、标点符号检查与“的/地/得”语法提示均在本地实时完成，小说正文绝对不会上传；插件无任何自动联网行为。
- **作用范围**：启用校对后默认检查工作区内所有 Markdown 文档，校对词典始终排除；开启 **启用全局生效** 后，检查范围扩展至当前笔记库内所有 Markdown 文档。
- **自定义 Markdown 表格词典（库内可编辑）**：自定义词典以纯 Markdown 表格形式保存在库内。支持中文路径 `校对词典/`（`错词.md`、`近义词.md`、`敏感词.md`）或英文路径 `Proofreading Dictionaries/`（`Typos.md`、`Synonyms.md`、`Sensitive Words.md`）。语言切换时始终保留已有的词典路径与文件：
  - **错词词典**：表头 `| 错词 | 建议 | 说明 |`（英文 `| Typo | Suggestion | Description |`）。
  - **近义词词典**：表头 `| 近义词组 | 说明 |`（英文 `| Synonym Group | Description |`），组内以 `、` 或逗号分隔，对称双向推荐（一词仅属于一组）。
  - **敏感词词典**：表头 `| 词语 | 建议 | 级别 | 例外 | 说明 |`（英文 `| Term | Suggestions | Level | Exceptions | Description |`），级别支持 `提示` / `警告`（英文 `Info` / `Warning`）。
  - **模板创建与补全**：首次开启 **启用校对** 或首次使用 **标注为词库**（桌面端右键或全平台命令）时自动创建缺失模板；点击 **补全缺失词典模板**（按钮 **补全模板**）可在不覆盖已有文件的前提下补齐缺失模板。
- **官方在线词库（插件内部 JSON 词典）**：
  - 与库内 Markdown 词典独立，运行于插件内部数据目录，初始状态均为“未下载”（0 条），绝不自动联网。
  - **基本错词库**：提供高置信中文错词检测，需在设置中点击 **更新基本错词库** 显式下载与更新。
  - **“的/地/得”规则词典**：仅支持中文文本。需在设置中点击 **更新规则词典** 下载后才可使用；初次下载完成后绝不自动开启。
- **标点符号检查**：默认关闭。根据标点符号两侧最近的正文文本语言智能提示中文全角或英文半角标点，不受界面语言影响；同时检查中文全角成对符号（如 `“”`、`‘’`、`（）`、`【】`、`《》`）的未闭合、孤立与连续同侧等情况。
- **“的/地/得”语法检查 (实验性)**：仅支持中文文本，默认关闭。在下载规则词典前处于禁用不可用状态；初次下载后不会自动开启；属于实验性保守规则，可能存在误报，开启后建议逐条确认。
- **5 种图形下划线与交互卡片**：在正文可视区域以 5 种专属下划线标注，悬停或点击即可展开建议卡片并一键就地替换；在任意 Markdown 文档（校对词典文件除外）中选中单行短文本后，桌面端可右键选择 **标注为词库**，全平台也可执行同名命令快速录入自定义词典。
- **社区官方词库贡献**：基础错词和“的/地/得”分类词项均可通过 `dictionary` 分支主动贡献；插件不会读取或上传正文，只有用户自行创建并提交的贡献文件会进入 Pull Request。
  1. 在 Fork 仓库中基于 `dictionary` 分支创建特性分支（topic branch）。
  2. 根据贡献类型复制模板：
     - 基础错词：将 `dict/contributions/_template.md` 复制为 `dict/contributions/<GitHub用户名>-<主题>.md`。
     - “的/地/得”：将 `dict/contributions/dedide/_template.md` 复制为 `dict/contributions/dedide/<GitHub用户名>-<主题>.md`。
  3. 保持 `license: CC0-1.0`，填写可核查的 `source`；“的/地/得”贡献还需填写分类词项、错误例句、正确例句和可选的正确反例。例句应简短、自拟或匿名化，不要提交小说原文、真实姓名、剧情细节或其他隐私内容。
  4. 严禁直接修改 `dict/basic-wrong-words.json` 或 `dict/dedide-lexicon.json`；向本仓库提交 Pull Request，并将目标分支设为 `dictionary`。
  5. GitHub Actions 会校验格式并生成对应候选 JSON；维护者合并即代表审核通过，随后只更新收到贡献的官方词典及其版本和日期。
  6. “的/地/得”可用分类及例句要求详见 [`dictionary` 分支贡献指南](https://github.com/HatanoChihiro/obsidian-webnovel-assistant/tree/dictionary#中文)。

#### 使用方法
1. 打开 **设置 → 校对**（位于“排版”右侧导航），开启 **启用校对**。
2. 首次启用会自动创建 `校对词典/`（或英文 `Proofreading Dictionaries/`）及其模板文件；若已有词典则直接加载。若误删模板文件，可点击 **补全缺失词典模板** 下方的 **补全模板** 按钮恢复。
3. 在作用范围内的任意 Markdown 文档中输入，可视区域将自动展示校对下划线。悬停或点击高亮文字可在卡片中点击建议项就地替换；如需检查工作区外的文档，请开启 **启用全局生效**。
4. 在任意 Markdown 文档（校对词典文件除外）中选中单行短文本，桌面端可右键选择 **标注为词库**；也可在 **设置 → 快捷键** 中为 **标注为词库** 分配快捷键，或将其添加至 Obsidian 移动端工具栏。首次使用会自动准备词典目录与模板。
5. 可在设置中按需开启 **标点符号检查**。
6. 如需使用中文在线词库与语法提示：
   - 点击 **更新基本错词库** 下载并更新中文基础错词库。
   - 点击 **更新规则词典** 下载规则词典后，方可手动开启 **“的/地/得”语法检查 (实验性)**。

## 移动端功能

### 复制本文档纯净文本

#### 功能说明
- **提取纯净文本**：一键将当前打开文档的所有正文内容无损提取，自动剥离所有的 Markdown 格式（标题、加粗、代码块、链接等）和 HTML 标签，仅保留纯净文本。
- **自动格式化**：复制时会在首行自动添加文档标题和一个空行，便于直接粘贴发布到各大网络小说平台或社交媒体。
- **解决移动端限制**：Obsidian 移动端的全选功能会遇到智能选择可视范围内文本的BUG，此功能可完整复制长篇文档。
- **快速访问**：支持通过命令面板、文件浏览器右键、编辑器右键菜单调用。

#### 使用方法

##### 方法一：通过命令面板（推荐移动端）
1. 打开命令面板（移动端可通过下拉拉出）。
2. 输入 `复制本文档纯净文本`
3. 执行后显示提示：`已复制本文档内容`

#### 方法二：通过右键菜单（桌面端）
1. 在正文区域右键（或点击右上角文件菜单）。
2. 选择 **复制本文档纯净文本**。

#### 适用场景
- 📱 需要将整篇文章快速分享到社交媒体或发布平台。
- 📱 移动端文档太长，手动全选困难。
- 💻 需要快速备份文本内容到外部编辑器。

### 浮动字数统计与专注计时（实验性）

#### 功能说明
- **移动端专属**: 在屏幕上显示浮动的字数统计及专注计时小窗。
- **实时更新**: 编辑时自动更新字数、目标完成度百分比，并同步运行专注计时。
- **贴边吸附与自动收起 (Edge Docking)**: 拖拽到屏幕左右边缘（≤35px）自动平移缩短收起为极简半透明手柄（透明度 0.35），不干涉打字；触摸或悬停手柄时平移展开。
- **设置调优**: 在移动端设置选项卡中支持通过滑动条自定义**专注度判定阈值**（超时未打字自动计入摸鱼时间）。

#### 使用方法
1. 打开插件设置 → 找到 **显示移动端浮动字数统计** 并开启；如需计时，再开启 **在移动端启用专注计时（实验性）**。
2. 浮动小窗包含：当前字数、章节目标、完成百分比；启用计时后可通过播放/暂停按钮控制专注时长。
3. 拖拽至屏幕左右边缘即可触发贴边收起。

> **提示**：启用浮动窗口后，状态栏的字数统计会自动隐藏，避免重复显示；实验性专注计时会过滤息屏与后台时间，数据与桌面端互通。

## 多端功能适配

插件支持 **桌面端 (Desktop)** 与 **移动端 (Mobile: 手机/平板)** 的全面联动与功能统一。核心创作功能（创作主页、写作工作台、字数/专注统计、伏笔管理、时间线看板、设定速查与图谱、任务看板）在移动端均可完整使用，并根据设备屏幕尺寸自动适配专属 UI 样式：

### 💻 桌面端 (Desktop)
- **全功能体验**: 支持包括创作主页、写作工作台、沉浸模式、桌面悬浮便签、OBS 直播 Overlay 及 Worker 后台时间追踪在内的所有功能。
- **高能计算**: 开启文件浏览器字数实时缓存与高性能图谱渲染。

### 📱 移动端 (Mobile - 手机 & 平板)
- **功能统一**: 手机与平板端共享完整的移动端功能，支持工作台全套视图、移动端浮动字数/专注计时小窗（支持边缘吸附半隐）、设定卡片速查与一键复制全文命令。
- **样式自动适应**:
  - **手机端 (`body.is-phone`)**: 自动触发手机专属极简自适应样式（问候语堆叠、紧凑型热力图、时间线触摸滑动卡片、按钮自适应换行）。
  - **平板端 (`body.is-tablet`)**: 自动触发平板大屏自适应样式（恢复同行操作按钮、扩展多列网格与侧边栏联动）。
- **平台限制区别**: 沉浸写作模式、OBS 直播 Overlay（需要本地 HTTP 服务）与多窗口桌面悬浮便签为桌面端独占。

## 常见问题

### Q: 如何退出沉浸写作模式？
A: 沉浸写作模式仅支持桌面端。将鼠标移动到屏幕最右上角，半隐藏的 **退出沉浸模式** 按钮会自动显示，点击即可退出；也可以打开命令面板再次执行 **进入/退出全屏沉浸写作模式**。建议提前在 **设置 → 快捷键** 中为该命令分配快捷键。`Esc` 会被插件锁定以避免只退出系统全屏而没有完整还原沉浸布局，因此不是正常退出方式。

### Q: 为什么校对结果不准确、漏报或误报？
A: 校对完全在本地运行，不使用 AI 或在线语义分析。当前官方本地词库仍在持续扩充，覆盖不足会造成漏报；“的/地/得”和标点等基于上下文规则的检查，也可能因专有名词、虚构表达或语义歧义产生误报。请将建议作为人工复核提示，不要盲目替换；缺失词条可通过 **标注为词库** 加入自定义词典。也欢迎按照本指南“校对”章节的贡献说明，向仓库 `dictionary` 分支贡献高置信词条和匿名化例句，共同完善官方词库。

### Q: 为什么使用 Obsidian 官方同步后，历史数据或便签没有同步？现在修复了吗？
A: 旧版插件曾将历史统计、便签和缓存分别保存在额外的 JSON 文件中，而 Obsidian 官方同步对第三方插件数据主要识别 `data.json`，因此可能出现设置已同步、历史或便签未同步的问题。最新版已将设置、历史统计和便签统一保存到 `data.json`，并会在对应数据尚未迁移时读取旧文件完成一次性迁移；`cache-data.json` 和按需下载的官方词库仍保留为设备本地数据，可重新生成或下载。建议所有设备更新到最新版，等待 Obsidian Sync 完成后重载插件；卸载、重装或移动端操作前仍建议备份完整 `data.json`。

### Q: 为什么开启 Fast Note Sync 的“配置项同步”后，WebNovel Assistant 会不断重载？
A: Fast Note Sync 可能会将 WebNovel Assistant 自动更新的本地缓存文件视为插件配置变更，并在每次同步后重载插件，从而形成循环。请在 Fast Note Sync 的 **同步排除** 中加入 `.obsidian/plugins/web-novel-assistant/cache-data.json`，并建议在所有设备上使用相同的排除规则。`cache-data.json` 仅保存可重建的设备本地缓存；WebNovel Assistant 的设置、历史统计和便签仍保存在 `data.json` 中，因此这条排除规则不会阻止这些配置和数据继续同步。

### Q: 字数统计不准确？
A: 
1. 检查是否启用了 **显示文件列表字数**
2. 尝试 **重建文件夹字数缓存**
3. 尝试 **重载/重启Obsidian**
4. 确认文件编码为 UTF-8

### Q: 安装失败或无法启用插件？
A:
1. 确认 Obsidian 版本不低于 1.8.7，并在 **设置 → 第三方插件** 中关闭受限模式后再启用插件。
2. 通过社区市场安装失败时，检查网络、代理或防火墙；可重启 Obsidian 后重试。
3. 手动安装时，确认 `main.js`、`manifest.json` 和 `styles.css` 位于同一个 `.obsidian/plugins/web-novel-assistant/` 文件夹内，且没有多嵌套一层解压目录。
4. 移动端（如 Android 设备）若遇到安装或加载失败，可能是系统内置的 WebView 内核版本过旧导致。请尝试更新 Android System WebView 以及系统默认浏览器/Chrome，重启 Obsidian 或重启设备后再试（此问题仅涉及移动端环境，桌面端无需排查 WebView）。
5. 若旧文件覆盖后仍无法加载需重新安装，建议先正常关闭 Obsidian，并提前备份 `data.json`，以保留插件设置、历史统计和未单独保存为 Markdown 文件的便签内容与状态。

### Q: 什么时候需要使用“重建设定缓存”？
A: 在 **命令面板（Ctrl/Cmd + P）→ `重建设定缓存`** 执行。它会重建设定条目和章节设定引用统计，并刷新编辑器高亮、工作台和关系图谱。以下情况尤其适用：
1. 刚通过“导入作品”导入章节后，需要为已有章节补齐设定引用统计。
2. 设定速查的下划线、悬浮卡片、工作台统计或关系图谱显示异常时。
3. 已有作品库首次安装本插件，且其中已包含设定文件和章节时。

### Q: 无法在命令面板找到“章节一览”和“设定一览”侧面板的打开命令？
A: “章节一览”和“设定一览”需要根据当前打开的作品判断，因此需要在聚焦作品章节文件时才能开启。

### Q: 设定速查下划线/悬浮卡片不显示，或写作台提示“暂无设定条目”？
A:
1. **检查工作区设置（常见配置误区）**：
   - **单部作品 / 全库即小说**：若你的库只写一本书，或各作品直接分布在根目录，**请将设置中的“工作区文件夹”保持为空**。
   - **多部作品放在总目录中**：工作区文件夹的设计定位是“包含多本小说的书库总目录”（如 `我的小说库/`），插件会自动将工作区内的直接子文件夹识别为各个独立作品。**请勿将单个作品的子文件夹（如 `我的小说库/作品A/`）直接添加为工作区**，否则会导致正文分卷（如 `第一卷`）被误判为独立作品，从而与同级 `设定/` 文件夹脱节。
2. **确认设定文件夹与词条格式**：
   - 设定文件需放置在作品根目录下的 `设定/` 文件夹（或在设置中自定义的文件夹名）内。
   - 设定词条需使用 `## 二级标题` 作为词条正名（支持在正文中使用 `**别名**：别名1、别名2` 补充别名）。
3. **尝试手动重建设定缓存**：
   - 按 `Ctrl/Cmd + P` 打开命令面板，执行 **`WebNovel Assistant: 重建设定缓存`**。

### Q: 章节排序不生效？
A:
1. 检查是否启用了 **智能章节排序**
2. 确认文件名符合规则格式
3. 尝试 **手动刷新章节排序**

### Q: OBS 叠加层无法显示？
A:
1. 检查是否启用了 **OBS 叠加层**
2. 确认端口没有被占用
3. 在浏览器中访问 `http://127.0.0.1:24816/` 测试
4. 检查防火墙设置

### Q: 伏笔文件找不到？
A:
1. 伏笔文件在当前文件的同级目录
2. 文件名默认为 `伏笔.md`
3. 可以在设置中修改文件名

### Q: 时间追踪不准确？
A:
1. 确认已开启时间追踪（命令面板）
2. 检查 **空闲超时阈值** 设置
3. 60 秒无操作会自动切换为摸鱼时间

### Q: 便签内容丢失？
A:
1. 关闭便签时会提示保存
2. 便签状态保存在插件设置中
3. 建议及时保存到文件

### Q: 移动端功能与桌面端有什么区别？
A:
- **功能高度统一**: 移动端（手机与平板）均可使用创作主页、写作工作台（含全章节概览、时间线、设定看板、任务看板）、专注计时与伏笔回收等核心功能。
- **独有移动端特性**: 提供「移动端浮动字数/计时小窗」（支持屏幕边缘吸附与收起）以及「复制当前文档全文」命令（完美解决移动端 Obsidian 无法全选可视区域外文字的问题）。
- **设备专属 UI 适配**: 手机端与平板端会根据屏幕尺寸自动应用最舒适的 UI 布局与触摸手势体验。
- **桌面端独占功能**: 沉浸写作模式（全屏打字机聚焦模式）、OBS 直播 Overlay 端口服务与多窗口桌面悬浮便签因移动端触摸交互及系统沙盒限制保留在桌面端。

### Q: 重装或彻底删除插件会导致写作历史与便签数据丢失吗？
A:
- **常规更新/覆盖更新**: 通过社区插件市场更新或直接覆盖 `main.js` 不会丢失数据。
- **完全卸载重装**: 若彻底删除插件文件夹 `.obsidian/plugins/web-novel-assistant/`，保存在该目录 `data.json` 中的插件设置、历史统计（每日字数与专注热力图数据）以及便签内容、位置和主题状态会被一并删除！若有未单独保存为 Markdown 文件的便签，其内容将会丢失（库中的普通 Markdown 文档不受影响）。
- **仅备份历史数据（桌面端）**: 若不需要保留插件设置和便签，可在 **设置 → WebNovel Assistant → 数据输出 → 历史数据备份** 中导出 JSON；重装后从同一位置恢复。恢复操作会替换当前历史统计。
- **完整备份（桌面端与移动端）**: 若需要同时保留设置或便签，或正在使用移动端，建议先正常关闭 Obsidian，再备份插件目录下的完整 `data.json`。重装后将此文件复制回原插件目录即可恢复设置、历史统计及便签。升级迁移后保留的 `history-data.json` 与 `notes-data.json` 仅作为旧数据备份，不再持续更新。

### Q: 与 Minimal 等第三方主题兼容，字数实时提醒 / Gutter 标签不显示或位置错位？
A: Minimal 主题默认对编辑器左侧 Gutter 侧栏容器及正文 margins 进行了较严格的隐藏与留白限制。你可以使用 Obsidian 的 **设置 → 外观 → CSS 代码片段 (CSS Snippets)** 功能，添加以下自定义 CSS 片段以解除隐藏限制并平移标签位置：

```css
/* 1. 解除容器限制与隐藏 */
.markdown-source-view.mod-cm6 .cm-gutters {
  display: flex !important;
  opacity: 1 !important;
  background-color: transparent !important;
}

.markdown-source-view.mod-cm6 .cm-gutter.webnovel-word-count-gutter {
  display: block !important;
  visibility: visible !important;
  opacity: 1 !important;
  overflow: visible !important;
}

/* 2. 重置标签容器定位，用 relative + left 强行向右平移 */
.webnovel-word-count-marker-wrapper {
  display: inline-flex !important;
  visibility: visible !important;
  opacity: 1 !important;
  white-space: nowrap !important;
  transform: none !important; /* 清除之前的 translateX 影响 */
  
  /* 控制位置：通过 relative 定位直接控制右移像素 */
  position: relative !important;
  left: 80px !important; /* 修改这个数值！数值越大，标签越往右移 */
}

/* 3. 给正文区足够的留白，防止标签往右移之后又撞上文字 */
.markdown-source-view.mod-cm6 .cm-sizer {
  margin-left: 60px !important; /* 如果右移后标签挤到了文字，就把这个数值调大 */
}
```
