## 快速开始

### 安装方法

#### 从 Obsidian 社区插件市场安装（推荐）
1. 打开 **设置 → 第三方插件 → 浏览**
2. 搜索 **"WebNovel Assistant"**
3. 点击 **安装**，然后 **启用**

#### 使用 BRAT
1. 安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件
2. 在 BRAT 设置中添加此仓库：`HatanoChihiro/obsidian-webnovel-assistant`
3. 启用插件

#### 手动安装
1. 从 [Releases](https://github.com/HatanoChihiro/obsidian-webnovel-assistant/releases) 下载最新版本的 `main.js` 和 `manifest.json`以及 `styles.css`
2. 在 Obsidian 库中创建文件夹：`.obsidian/plugins/web-novel-assistant/`
3. 将下载的文件放入该文件夹
4. 重启 Obsidian，在设置 → 第三方插件中启用

> ⚠️ **数据备份提醒**：若需完全卸载或重新安装插件，请务必提前备份 `.obsidian/plugins/web-novel-assistant/` 目录下的 `history-data.json`（历史字数与专注统计数据），重新安装后将其放回原目录即可恢复所有历史统计。

### 首次使用

1. 打开任意 Markdown 文件
2. 状态栏会显示当前文件的字数统计
3. 点击状态栏可以设置目标字数

## 核心功能

### 创作主页

#### 功能说明
- **全宽仪表盘**: 2行×2列网格布局，突破 Obsidian 正文宽度限制，全宽填满编辑器可视区域
- **动态欢迎语**: 根据时间段自动变化（早上好、下午好、夜深了等），显示总字数（工作区实际字数）与今日新增
- **作品总览**: 连载中（含限时任务追踪进度）、存稿中、已暂停、已完结一目了然
- **数据面板**: 右列显示效率总览、365热力图、近30日趋势
- **窄屏自适应**: 编辑器宽度 <1200px 时自动切换为单列布局
- **一键新建**: 欢迎区右侧「+ 新增作品」按钮，弹窗填写元数据后自动创建文件夹和作品信息文件

#### 使用方法
1. 启用插件后，在设置中启用创作主页
2. 主页文件自动生成在工作区第一个文件夹下（默认名称：创作主页.md）
3. 点击主页文件即可进入创作主页
4. 主页自动切换为预览/阅读模式，文档属性和标题已隐藏

#### 新增作品
1. 点击欢迎区右侧「+ 新增作品」按钮
2. 在弹窗中填写作品名称、简介、类型、总字数目标
3. 点击「创建」，自动生成作品文件夹和作品信息文件

#### 导入已有作品
1. 在创作主页的作品区点击「导入作品」按钮，或在文件树中右键点击任意作品文件夹选择「导入作品」。
2. 在弹窗中选择需要导入的单本长篇 txt 或 md 格式小说文件。
3. 系统将依据您在插件设置中配置的【自定义章节命名规则】，自动扫描、切割文本内容并按章节批量生成 Markdown 文档。
4. > 💡 **小提示**：如果您的原作品为 Word 格式（`.docx` / `.doc`），建议先使用 Pandoc 或其他工具将其另存/转换为 `.md` 文件再进行导入，以保留原有的文本格式。

#### 自定义主页欢迎语
1. 打开插件设置
2. 找到 **主页欢迎语**
3. 输入自定义文本，留空则使用根据时间段自动变化的欢迎语

### 写作工作台

#### 功能说明
写作工作台是由原“章节一览”全新升级而来的综合性写作管理中心，集成了 6 个主要的选项卡面板：

1. **全章节面板**：
   - 快速创建章节，修改章节名称与摘要。
   - 支持**手动拖拽排序**（若文件名包含章节序号，拖拽后自动按新顺序自动重命名后续文件）。
   - 卡片底部的徽章会自动显示当前章节中出现的**设定**与**伏笔**，点击即可快速预览。
   - **支持多章节模板配置**：可在设置中配置多个模板，创建下一章时按需选择模板。
2. **时间轴面板**：
   - 以竖向时间流展示小说事件，支持把章节卡片拖拽到特定时间节点绑定事件，支持拖拽事件卡片重新排序。
   - 底部内置未关联章节悬浮窗，浮动关联连线高亮，不再遮挡时间轴。
3. **设定面板**：
   - 支持**表格视图**、**卡片视图**与**全量设定图谱视图**快速切换。
   - 自动统计出场总次数和出场章节，支持图谱节点双击跳转到对应 Markdown 设定文档。
4. **伏笔看板面板**：
   - 全新专用的伏笔集中展示与管理视图。
   - 按照 `待回收`（包含未回收与阶段推进）、`已回收`、`已废弃` 三大分类栏目归组展示伏笔卡片，支持分类折叠。
   - 提供顶栏关键词搜索框，可实时按标题、描述或标签过滤伏笔卡片。
   - 点击伏笔卡片可精准跳转并闪烁高亮定位到对应源笔记的具体行。
5. **任务看板面板**：
   - 将限时任务集中在工作台中以卡片网格显示，支持直接在工作台新建限时任务。
   - 针对未完成的进行中任务提供**放弃任务**按钮及二次确认，放弃后状态标记为 `已放弃` (`abandoned`) 并保留历史字数记录。
6. **便签管理面板**：
   - 统一集中管理全库所有悬浮与沉浸便签，支持新建、编辑、修改主题与删除便签，与桌面悬浮便签与沉浸便签双向实时同步。

#### 使用方法

##### 打开写作工作台
1. 命令面板（Ctrl/Cmd + P）输入 `打开写作工作台`
2. 或点击左侧 Ribbon 菜单中的工作台图标
3. 打开任意章节文件后，工作台会自动识别当前作品并展示对应内容。

##### 启用章节模板
1. 打开插件设置 → **启用章节模板**，将其开启。
2. 在下方的输入框中填写模板文档的相对路径（例如 `Templates/ChapterTemplate.md`）。
3. 之后新建章节将自动应用该模板内容（包含命令创建的新章节）。

### 沉浸写作模式

#### 功能说明
- **全屏专注**: 进入全屏创作环境，隐藏 Obsidian 侧边栏、状态栏、顶栏等所有干扰元素。
- **动态仪表盘**: 顶部实时显示小说标题、专注/摸鱼时长、今日净增字数及目标进度。
- **打字机居中滚动与行淡化**: 支持打字机居中滚动（Typewriter Scroll）与上下文行淡化（Line Dimming），可在中央状态栏开关一键切换，专注当前行创作。
- **插槽化布局**: 自由分配辅助面板到主编辑区的上下左右四个区域，无分配的面板区域自动贴边，主编辑区最大化。
- **参考文档**: 在章节上左击开启文档到主编辑区，右击到右侧参考区。

#### 使用方法
1. 打开任意小说章节（Markdown 文件）。
2. 命令面板（Ctrl/Cmd + P）输入 `进入/退出 沉浸写作模式`。
3. 或点击侧边栏 Ribbon 图标。

#### 相关设置
- **打字机居中滚动**: 开启后光标所在行保持在屏幕中央垂直居中。
- **上下文行淡化**: 开启后非聚焦行淡化显示，提升专注度。
- **插槽布局**: 在设置页面的沉浸模式选项卡中，通过可视化布局器自由拖配各面板（章节列表、伏笔、时间线、便签、参考文档、章节一览）到上下左右四个区域。
- **自动隐藏属性面板**: 开启后在沉浸模式下自动隐藏 Markdown 文件顶部的属性面板区域。
- **沉浸模式便签尺寸**: 自定义便签列表中的卡片边长（默认 280px）。
- **沉浸模式便签字号**: 调整便签预览时的字体大小。

### 工作区设置

#### 功能说明
- **自定义插件工作区**：指定插件工作的文件夹范围
- **影响范围**：
  - ✅ 字数统计（状态栏、文件浏览器）
  - ✅ 写作状态面板的历史记录
  - ✅ 文件修改监听和缓存构建
  - ❌ 不影响：伏笔、时间线、便签等功能

#### 使用方法
1. 打开插件设置
2. 找到 **工作区文件夹**
3. 输入文件夹路径（如 `小说/第一部`）
4. 多个文件夹用逗号分隔（如 `小说/第一部, 小说/第二部`）
5. 留空则全局生效（所有文件都统计）

#### 使用场景
- 同一个库中有多个项目，只想统计特定项目的字数
- 避免笔记、日记等非小说内容影响统计
- 提高性能（只监听和缓存指定文件夹）

### 字数统计

#### 功能说明
- **精确统计中文字数**：准确识别中文、英文、数字
- **实时更新**：编辑时自动更新字数
- **净增字数**：显示本次会话新增的字数[text](../main.js) [text](../styles.css)
- **状态栏显示**：在 Obsidian 底部状态栏显示
- **严格章节模式**：限制字数相关功能仅在符合命名规则的章节中生效（详见 [严格章节模式](#严格章节模式)）
- **字数实时提醒**：在编辑器左侧实时显示累计字数提醒（详见 [字数实时提醒](#字数实时提醒)）

#### 使用方法
1. 打开任意 Markdown 文件
2. 状态栏自动显示字数：`1,234 字 | 净增: +56 字`
3. 点击状态栏可以快速设置目标

#### 相关设置
- **工作区文件夹**：限制统计范围（详见 [工作区设置](#工作区设置)）
- **非工作区文件**：不在工作区范围内的文件仍会在状态栏显示基本字数（不含追踪状态和净增字数）

- ✅ 统计：中文字符、英文单词、数字
- ❌ 不统计：Markdown 语法、代码块、注释、YAML frontmatter

#### 统计稳定性与防跳变 [HOT]
为了解决 Obsidian 插件中常见的”字数统计激增/减少”问题，本插件采用了一套多重校验架构：
- **实时同步**：编辑器内的改动会即时同步到内存缓存。
- **文件基准同步**：当文件被自动保存（触发 modify 事件）时，插件会通过时间戳校验来对比当前缓存与磁盘内容的差异，确保增量计算是基于同一个基准点的。
- **冷启动保护**：在插件加载和索引构建期间，所有的文件改动都会被实时捕捉以更新缓存基准，防止在布局就绪后产生巨大的虚假增量。

#### 字数统计模式

插件提供三种字数统计算法，适配不同创作场景：

| 模式 | 规则 | 适用场景 |
|------|------|---------|
| **网文模式** | 所有非空白字符均算1个字（含标点） | 起点中文网、晋江文学城等网文平台的字数计算规则 |
| **标准模式**（默认） | 中文逐字 + 英文按词 + 全角标点算字，半角标点不计 | Word、WPS 等文档工具的常用字数方案 |
| **原生模式** | 中文逐字 + 英文按词，忽略所有标点 | 接近 Obsidian 内置字数统计 |

##### 切换方法
1. 打开插件设置 → **字数显示**
2. 找到 **字数统计模式**
3. 从下拉菜单中选择所需模式
4. 切换后自动全库重新计算字数

> **💡 提示**：不同模式下同一篇文档的字数可能差异较大，这是正常现象。选择与你投稿平台一致的统计模式即可。

### 目标追踪

#### 功能说明
- **章节目标**：为每个章节设置独立的目标字数
- **今日目标**：设置今日写作目标
- **进度显示**：实时显示完成百分比
- **进度条**：可视化显示进度

#### 使用方法

##### 设置章节目标
1. 右键点击文件 → **设定本章目标字数**
2. 输入目标字数（如 3000）
3. 状态栏显示进度：`1,234 / 3,000 (41%)`

##### 设置今日目标
1. 打开插件设置
2. 找到 **今日目标字数**
3. 输入目标（如 5000）

#### 相关设置
- **默认目标字数**：新文件的默认目标（默认 3000 字）
- **今日目标字数**：今日写作目标（默认 5000 字）
- **显示目标进度**：是否在状态栏显示进度（桌面端专属，默认启用）

##### 查看进度
- **状态栏**：显示当前文件进度
- **写作状态面板**：显示详细统计（点击左侧 Ribbon 图标）

### 严格章节模式

#### 功能说明
- **精准过滤**：所有涉及字数相关（章节目标、字数统计、左侧提醒等）的功能均只在符合“章节命名规则”的文档中生效。
- **排除干扰**：开启后，写大纲、设定、草稿等非章节文档将不再计入每日字数进度，也不会显示进度条或字数提醒标签。
- **灵活性**：如果需要统计特定的具名章节（如“番外”），只需在排序规则中添加相应的匹配规则即可。
- **可设置例外目录**：如果需要统计单个目录下的所有文档（如“短篇”），可将该目录设置为例外。

#### 使用方法
1. 打开插件设置 -> **核心设置**。
2. 启用 **启用严格章节模式**。
3. 确保你的章节命名符合 **章节命名规则配置** 中的任一启用规则。

### 字数实时提醒

#### 功能说明
- **字数提醒**：在编辑器左侧（行号区域）实时显示累计字数。
- **视觉辅助**：例如设置每 2000 字提醒一次，编辑器左侧会自动出现 `2000`、`4000` 等字数标签，帮助作者掌控写作节奏。
- **智能定位**：标签精确显示在达到对应字数的那一行。

#### 使用方法
1. 打开插件设置 -> **核心设置**。
2. 启用 **启用字数实时提醒**。
3. 在 **字数提醒间隔** 中输入目标字数（如 2000）。
4. 在编辑器中写作，左侧会自动出现提示标签。

#### 相关设置
- **字数提醒间隔**：设置每隔多少字显示一次提示。
- **与严格模式联动**：若开启严格模式，则提醒仅在符合章节规则的文件中显示。

### 时间追踪

#### 功能说明
- **专注时间**：统计实际写作时间
- **摸鱼时间**：统计空闲时间
- **自动检测**：60 秒无操作自动切换为摸鱼
- **历史记录**：保存每日统计数据

#### 使用方法

##### 开始追踪
1. 打开命令面板（Ctrl/Cmd + P）
2. 输入 `开始/暂停 摸鱼时间统计`
3. 开始写作，插件自动追踪时间

##### 查看统计
- **状态栏**：显示今日专注时间
- **写作状态面板**：显示详细时间分布
- **历史统计**：点击面板中的 "查看历史统计"

##### 重置统计
- 命令面板 → `重置直播统计数据`
- 清空当前会话的时间和字数统计

#### 相关设置
- **空闲超时阈值**：多少毫秒无操作算作摸鱼（默认 60000 = 60 秒）

> **注意**：移动端不支持时间追踪功能（需要 Worker 支持）

### 文件浏览器字数显示

#### 功能说明
- **文件夹字数**：显示文件夹内所有文件的总字数
- **文件字数**：显示单个文件的字数
- **实时更新**：修改文件后自动更新
- **工作区过滤**：只显示指定文件夹的字数
- **性能优化**：使用缓存机制，避免频繁计算

> **注意**：此功能默认关闭，因为在大型项目中可能影响性能。如需使用，请在设置中手动启用。

#### 使用方法

##### 启用功能
1. 打开插件设置
2. 启用 **文件浏览器字数统计**
3. 插件会自动构建缓存（可能需要几秒钟）
4. 文件浏览器中会显示字数：`第一章 (3,456)`

##### 重建缓存
如果字数显示不正确：
1. 命令面板 → `重建文件夹字数缓存`
2. 等待重建完成

#### 相关设置
- **文件浏览器字数统计**：是否启用此功能（默认关闭，避免性能问题）
- **工作区文件夹**：限制统计范围（详见 [工作区设置](#工作区设置)）

### 智能章节排序

#### 功能说明
- **自动排序**：按章节编号自动排序
- **多种格式**：默认支持阿拉伯数字、中文数字
- **文件夹排序**：文件夹（如"第1卷"）也能参与排序，同编号文件夹排在文件前
- **自定义规则**：支持自定义正则表达式
- **实时生效**：创建/重命名文件后自动排序
- **拖拽排序**：非章节文件和章节区块可拖拽调整顺序，章节区块整体移动

> **💡 拖拽排序**：
> 智能章节排序内置了拖拽排序功能：
> - **章节区块**：所有章节文件作为一个整体区块，可拖拽移动位置（如拖到非章节文件下方）
> - **非章节文件**：可拖拽调整顺序，穿插在章节区块上下
> - 章节区块内部始终按编号排序，不可单独拖拽某章

#### 使用方法

##### 启用功能
1. 打开插件设置
2. 启用 **智能章节排序**
3. 文件浏览器中的章节会自动排序

##### 支持的格式
- 阿拉伯数字：`第1章`、`第01章`、`Chapter 1`
- 中文数字：`第一章`、`第二十三章`、`第一百章`、`第九百九十九章`
- 具名章节：`大纲`、`番外`、`楔子`（需在规则中配置）
- 纯数字：`1`、`01`、`001`
- 自定义规则

##### 自定义规则

1. 打开插件设置 -> **智能排序**。
2. 找到 **排序规则配置**。
3. 点击 **+ 添加新规则**。
4. 输入规则名称和正则表达式。
5. **调整顺序**：使用规则左侧的 **▲/▼** 按钮调整优先级。
6. **启用/禁用**：每个规则都可以单独开关。

> **💡 正则规则核心原理**：
> - **有括号 `(\d+)` 的规则**：括号捕获编号，插件按编号排序。如 `第1章` → 编号1，`第2章` → 编号2。
> - **没有括号的规则**：不提取编号，视为"具名章节"，按文件名字典序排列。如 `前言`、`番外`。
> - **规则顺序决定位置**：先匹配到的规则分组排在上面。想把番外放在正文后面，就把番外规则放在编号规则下面。

##### 默认预设规则

插件在设置中预设了 5 个常用规则，前 3 个默认开启，你可以随时在设置中调整开启状态：

**规则 1：阿拉伯数字（第1章、第01章）**
```
名称：阿拉伯数字（第1章、第01章）
正则：^(?:第(\d+)[章节回卷部册篇]?|第?(\d+)[章节回卷部册篇])
启用：是
```
支持格式：`第1章`、`第01章`、`1章`、`第1节`、`第1回`、`第1卷`、`第1部`、`第1册`、`第1篇`

**规则 2：中文数字（第一章、第二章）**
```
名称：中文数字（第一章、第二章）
正则：^(?:第([零一二三四五六七八九十百千万壹贰叁肆伍陆柒捌玖拾佰仟萬〇]+)[章节回卷部册篇]?|第?([零一二三四五六七八九十百千万壹贰叁肆伍陆柒捌玖拾佰仟萬〇]+)[章节回卷部册篇])
启用：是
```
支持格式：`第一章`、`第二十三章`、`第一百章`、`第九百九十九章`（支持一到九百九十九）

**规则 3：纯数字及带标题（1、01、001 标题）**
```
名称：纯数字及带标题（1、01、001 标题）
正则：^(\d+)(?:[ \-].*)?$
启用：是
```
支持格式：`1`、`01`、`001 序章`（纯数字或空格/连字符后接标题的文件名，**不包含小数点**）

**规则 4：英文章节 (Chapter 1, Ch.1)**
```
名称：英文章节 (Chapter 1, Ch.1)
正则：^[Cc]h(?:apter)?\.?\s*(\d+)
启用：否
```
支持格式：`Chapter 1`、`Ch 01`、`ch.1`

**规则 5：全能括号 ( (1)、【30】 )**
```
名称：全能括号 ( (1)、【30】 )
正则：^[（\(【「{]([0-9零一二三四五六七八九十百千万]+)[）\)】」}]
启用：否
```
支持格式：`(1)`、`（一）`、`【30】`、`「一百」`、`{2}`

##### 自定义规则示例

除了默认规则，你还可以添加自己的规则：

**小数点章节**（如：1.1、1.2、2.1、2.2）
```
名称：小数点章节
正则：^(\d+\.\d+)
启用：是
```


**数字与小数混合排序**（如：1、1.5、2、2.1）

如果你希望纯数字和小数点章节严格按照数学大小混合穿插排序，必须**关闭默认的纯数字规则**，并只启用这一条“全包含”规则（将它们归为同一类，底层才能执行大小比较）：
```
名称：数字与小数混合排序
正则：^(\d+(?:\.\d+)?)(?:[ \-].*)?$
启用：是
```

**卷章节**（如：第一卷第一章）
```
名称：卷章节
正则：^第.+卷第?(\d+)[章节]?
启用：是
```

**具名章节 — 多个名称合并为一条规则**（如：前言、番外、后记）

一条规则就能匹配多种文件名，用 `|` 分隔即可，无需逐个添加：
```
名称：特殊章节（前言/番外/后记等）
正则：^(前言|序章|楔子|引子|番外|外传|后记|尾声|附录)
启用：是
```
这条规则没有括号捕获编号，所以匹配的文件都按文件名字典序排列。你可以通过调整规则顺序来控制位置——放在编号规则上方则排在正文前面，放在下方则排在后面。

**带编号的具名章节**（如：番外1、番外2）

如果具名章节本身带编号，加上括号捕获编号即可按数字排序：
```
名称：番外系列
正则：^番外(\d+)
启用：是
```
这样 `番外1` → 编号1，`番外2` → 编号2，自动按顺序排列。

> **提示**：
> - 正则表达式中的 `(\d+)` 或 `(\d+\.\d+)` 用于捕获章节编号
> - 规则的顺序决定了排序的优先级（上面的规则优先）
> - 可以同时启用多个规则，插件会按顺序匹配
> - `|` 表示"或"，可以一条规则匹配多种文件名

> **⚠️ 重要提醒**：
> 如果同时启用了**数字规则**（如 `^(\d+)(?:[ \-].*)?$`）和**小数点规则**（如 `^(\d+\.\d+)`），建议将小数点规则放在数字规则**上方**。虽然新版默认数字规则已经排除了对小数点的误判，但对于自定义数字规则，顺序依然很重要。
>
> **正确顺序**：
> 1. 小数点章节 `^(\d+\.\d+)` ✅
> 2. 纯数字 `^(\d+)(?:[ \-].*)?$` ✅


#### 相关设置
- **启用智能章节排序**：总开关。
- **排序规则配置**：核心配置区域，支持添加、删除、禁用和 ▲/▼ 排序。

### 设定速查

#### 功能说明
- **字典式设定库**：在设定文件夹下创建分类文档（如 `角色志.md`、`道具志.md`），插件自动扫描识别
- **自动精准标注**：在分类文档中使用二级标题（`##`）创建设定词条，并在正文补充 `**别名**：xxx`。当你在小说正文敲出这些名字时，系统自动打上虚线下划线
- **悬浮速查**：鼠标悬停在标注文字上，即可弹出精准定位到该词条的小窗口，无需切出编辑页
- **右键"边写边建"**：在编辑器中直接划选一个新道具或角色的名字，右键点击"添加为新设定"，即可在弹窗中极速录入
- **别名支持**：支持 YAML 中的 aliases 字段和正文中的 `**别名**：xxx` 两种方式

#### 使用方法

##### 配置设定文件夹
1. 打开插件设置 → **创作辅助**
2. 找到 **设定文件夹名称**
3. 输入存放设定文件的文件夹名称（默认"设定"）
4. 在每部作品的目录下创建该文件夹，将分类设定文档放入其中

##### 创建设定文档（字典大纲模式）
在设定文件夹下创建分类文档，使用 `## 二级标题` 作为词条正名：

```markdown
# 角色志

## 张三
主角，少年剑客。
**别名**：三哥、小张

## 李四
反派，阴险狡诈。
**别名**：四爷

## 王五
配角，忠诚的伙伴。
```

> **💡 提示**：
> - 每个二级标题（`##`）是一个独立词条，标题文本即正名
> - 插件仅识别二级标题，一级标题（`#`）和三级标题（`###`）不会被当作词条
> - 别名用 `**别名**：xxx` 格式写在词条正文内，多个别名用逗号或顿号分隔
> - 别名也支持 YAML aliases 字段（兼容旧版写法）

##### 使用设定速查
1. 在正文中输入角色名或别名（如"张三"或"三哥"）
2. 文字会自动出现虚线下划线
3. 鼠标悬停即可预览设定卡片内容，精准定位到对应词条

##### 右键添加新设定
1. 在编辑器中选中一个新名字（如"玄铁剑"）或直接点击命令/菜单
2. 右键 → **添加为新设定**
3. 在弹窗中填写设定名称、选择/输入分类文档、预设类型（支持预设下拉补全）、别名与详细描述
4. 支持在弹窗内直接可视化添加**设定关系**（可选择目标设定及输入描述关系，保存时自动落盘格式规范的 `### 关系` 语法）
5. 点击保存，设定自动格式化写入对应的分类 Markdown 文档

> **注意**：设定速查的编辑器高亮下划线功能仅在桌面端可用（移动端支持弹窗新建与快捷命令添加）。

- **设定文件夹名称**：默认 `设定`，可自定义

### 设定图谱

#### 功能说明
- **自动关系解析**：一键生成角色之间的关系图，基于“设定速查”解析到的文中互相提及关系（虚线连接）。
- **显式关系定义**：在角色设定的 Markdown 文件中，使用 `### 关系` 或 `### Relations` 建立显式关系（实线连接）。格式支持无序列表，如 `- [目标人物]: 关系说明`。
- **自定义样式**：支持高度定制的外观（颜色、线条、虚线等），并可通过 CSS Snippets 进行深度魔改。
- **动态交互**：支持双击跳转到角色文档，滚轮缩放，右键平移画布。悬停高亮关联节点和连线。

#### 使用方法

##### 开启设定图谱
1. 右键任意**设定文件夹内**的文档，在右键菜单中选择 **打开设定图谱**。
2. 插件会自动从当前文档所在的设定文件夹向外推断所属小说，加载全局人物并在右侧边栏打开图谱视图。

##### 定义显式关系
1. 在设定文档中（例如“人物设定.md”），找到你需要添加关系的角色标题（如 `## 主角`）。
2. 在该角色名下新建一个名为 `### 关系` 的三级标题。
3. 按照如下格式填写（加粗表示**关系名**，冒号后是目标角色名，多个角色用逗号或顿号分隔）：
```markdown
## 李雷
**别名**：小雷
**描述**：男主角

### 关系
- **青梅竹马**: 韩梅梅
- **宿敌**: 王明, 魏华
```
4. 设定图谱会解析 `**关系名称**: 目标名称` 并在图谱中以实线绘制箭头和标签。

#### 相关设置
- **设定卡片折叠**：由于设定速查卡片字数可能较多，插件支持将这些子标题在悬浮窗内折叠显示。可在插件设置面板开启折叠功能（默认全局展开）。

### 写作工作台

#### 功能说明
写作工作台是由原“章节一览”全新升级而来的综合性写作管理中心，集成了 5 个主要的选项卡面板：

1. **全章节面板**：
   - 快速创建章节，修改章节名称与摘要。
   - 支持**手动拖拽排序**（若文件名包含章节序号，拖拽后自动按新顺序自动重命名后续文件）。
   - 卡片底部的徽章会自动显示当前章节中出现的**设定**与**伏笔**，点击即可快速预览。
   - **支持章节模板**：可在设置中开启“启用章节模板”并指定模板路径，开启后新增章节自动应用模板。
2. **时间轴面板**：
   - 以竖向时间流展示小说事件，支持把章节卡片拖拽到特定时间节点绑定事件，支持拖拽事件卡片重新排序。
   - 底部内置未关联章节悬浮窗，浮动关联连线高亮，不再遮挡时间轴。
3. **设定面板**：
   - 支持**表格视图**、**卡片视图**与**全量设定图谱视图**快速切换。
   - 自动统计出场总次数和出场章节，支持图谱节点双击跳转到对应 Markdown 设定文档。
4. **任务看板面板**：
   - 将限时任务集中在工作台中以卡片网格显示，支持直接在工作台新建限时任务。
   - 针对未完成的进行中任务提供**放弃任务**按钮及二次确认，放弃后状态标记为 `已放弃` (`abandoned`) 并保留历史字数记录。
5. **便签管理面板**：
   - 统一集中管理全库所有悬浮与沉浸便签，支持新建、编辑、修改主题与删除便签，与桌面悬浮便签与沉浸便签双向实时同步。

#### 使用方法

##### 打开写作工作台
1. 命令面板（Ctrl/Cmd + P）输入 `打开写作工作台`
2. 或点击左侧 Ribbon 菜单中的工作台图标
3. 打开任意章节文件后，工作台会自动识别当前作品并展示对应内容。

##### 启用章节模板
1. 打开插件设置 → **启用章节模板**，将其开启。
2. 在下方的输入框中填写模板文档的相对路径（例如 `Templates/ChapterTemplate.md`）。
3. 之后新建章节将自动应用该模板内容（包含命令创建的新章节）。

## 移动端功能

### 复制本文档纯净文本

#### 功能说明
- **提取纯净文本**：一键将当前打开文档的所有正文内容无损提取，自动剥离所有的 Markdown 格式（标题、加粗、代码块、链接等）和 HTML 标签，仅保留纯净文本。
- **自动格式化**：复制时会在首行自动添加文档标题和一个空行，便于直接粘贴发布到各大网络小说平台或社交媒体。
- **解决移动端限制**：Obsidian 移动端的全选功能会遇到智能选择可视范围内文本的BUG，此功能可完整复制长篇文档。
- **快速访问**：支持通过命令面板、文件浏览器右键、编辑器右键菜单调用。

#### 使用方法

##### 方法一：通过命令面板（推荐移动端）
1. 打开命令面板（移动端可通过下拉拉出）。
2. 输入 `复制本文档纯净文本`
3. 执行后显示提示：`已复制本文档内容`

#### 方法二：通过右键菜单（桌面端）
1. 在正文区域右键（或点击右上角文件菜单）。
2. 选择 **复制本文档纯净文本**。

#### 适用场景
- 📱 需要将整篇文章快速分享到社交媒体或发布平台。
- 📱 移动端文档太长，手动全选困难。
- 💻 需要快速备份文本内容到外部编辑器。

### 浮动字数统计与专注计时（实验性）

#### 功能说明
- **移动端专属**: 在屏幕上显示浮动的字数统计及专注计时小窗。
- **实时更新**: 编辑时自动更新字数、目标完成度百分比，并同步运行专注计时。
- **贴边吸附与自动收起 (Edge Docking)**: 拖拽到屏幕左右边缘（≤35px）自动平移缩短收起为极简半透明手柄（透明度 0.35），不干涉打字；触摸或悬停手柄时平移展开。
- **设置调优**: 在移动端设置选项卡中支持通过滑动条自定义**专注度判定阈值**（超时未打字自动计入摸鱼时间）。

#### 使用方法
1. 打开插件设置 → 找到 **显示移动端浮动字数统计** 并开启。
2. 浮动小窗包含：当前字数、章节目标、完成百分比与专注时长。
3. 拖拽至屏幕左右边缘即可触发贴边收起。

> **提示**：启用浮动窗口后，状态栏的字数统计会自动隐藏，避免重复显示。数据与桌面端全量互通。

## 多端功能适配

- **全功能体验**: 支持包括创作主页、写作工作台、沉浸模式、桌面悬浮便签、OBS 直播 Overlay 及 Worker 后台时间追踪在内的所有功能。
- **高能计算**: 开启文件浏览器字数实时缓存与高性能图谱渲染。

### 📱 移动端 (Mobile - 手机 & 平板)
- **功能统一**: 手机与平板端共享完整的移动端功能，支持工作台全套视图、移动端浮动字数/专注计时小窗（支持边缘吸附半隐）、设定卡片速查与一键复制全文命令。
- **样式自动适应**:
  - **手机端 (`body.is-phone`)**: 自动触发手机专属极简自适应样式（问候语堆叠、紧凑型热力图、时间线触摸滑动卡片、按钮自适应换行）。
  - **平板端 (`body.is-tablet`)**: 自动触发平板大屏自适应样式（恢复同行操作按钮、扩展多列网格与侧边栏联动）。
- **平台限制区别**: 沉浸写作模式、OBS 直播 Overlay（需要本地 HTTP 服务）与多窗口桌面悬浮便签为桌面端独占。

## 常见问题

### Q: 字数统计不准确？
A: 
1. 检查是否启用了 **文件浏览器字数统计**
2. 尝试 **重建文件夹字数缓存**
3. 尝试 **重载/重启Obsidian**
4. 确认文件编码为 UTF-8

### Q: 章节排序不生效？
A:
1. 检查是否启用了 **智能章节排序**
2. 确认文件名符合规则格式
3. 尝试 **手动刷新章节排序**

### Q: OBS 叠加层无法显示？
A:
1. 检查是否启用了 **OBS 叠加层**
2. 确认端口没有被占用
3. 在浏览器中访问 `http://127.0.0.1:24816/` 测试
4. 检查防火墙设置

### Q: 伏笔文件找不到？
A:
1. 伏笔文件在当前文件的同级目录
2. 文件名默认为 `伏笔.md`
3. 可以在设置中修改文件名

### Q: 时间追踪不准确？
A:
1. 确认已开启时间追踪（命令面板）
2. 检查 **空闲超时阈值** 设置
3. 60 秒无操作会自动切换为摸鱼时间

### Q: 便签内容丢失？
A:
1. 关闭便签时会提示保存
2. 便签状态保存在插件设置中
3. 建议及时保存到文件

### Q: 移动端功能与桌面端有什么区别？
A:
- **功能高度统一**: 移动端（手机与平板）均可使用创作主页、写作工作台（含全章节概览、时间线、设定看板、任务看板）、专注计时与伏笔回收等核心功能。
- **独有移动端特性**: 提供「移动端浮动字数/计时小窗」（支持屏幕边缘吸附与收起）以及「复制当前文档全文」命令（完美解决移动端 Obsidian 无法全选可视区域外文字的问题）。
- **设备专属 UI 适配**: 手机端与平板端会根据屏幕尺寸自动应用最舒适的 UI 布局与触摸手势体验。
- **桌面端独占功能**: 沉浸写作模式（全屏打字机聚焦模式）、OBS 直播 Overlay 端口服务与多窗口桌面悬浮便签因移动端触摸交互及系统沙盒限制保留在桌面端。

### Q: 重装或彻底删除插件会导致写作历史数据丢失吗？
A:
- **常规更新/覆盖更新**: 通过社区插件市场更新或直接覆盖 `main.js` 不会丢失数据。
- **完全卸载重装**: 若彻底删除插件文件夹 `.obsidian/plugins/web-novel-assistant/`，保存在该目录下的历史统计文件 `history-data.json`（包含每日字数与专注热力图数据）会被清空！
- **备份恢复方法**: 重装前请手动备份 `history-data.json`，重装完成后将该文件复制回插件目录即可恢复所有历史统计数据。

### Q: 与 Minimal 等第三方主题兼容，字数实时提醒 / Gutter 标签不显示或位置错位？
A: Minimal 主题默认对编辑器左侧 Gutter 侧栏容器及正文 margins 进行了较严格的隐藏与留白限制。你可以使用 Obsidian 的 **设置 → 外观 → CSS 代码片段 (CSS Snippets)** 功能，添加以下自定义 CSS 片段以解除隐藏限制并平移标签位置：

```css
/* 1. 解除容器限制与隐藏 */
.markdown-source-view.mod-cm6 .cm-gutters {
  display: flex !important;
  opacity: 1 !important;
  background-color: transparent !important;
}

.markdown-source-view.mod-cm6 .cm-gutter.webnovel-word-count-gutter {
  display: block !important;
  visibility: visible !important;
  opacity: 1 !important;
  overflow: visible !important;
}

/* 2. 重置标签容器定位，用 relative + left 强行向右平移 */
.webnovel-word-count-marker-wrapper {
  display: inline-flex !important;
  visibility: visible !important;
  opacity: 1 !important;
  white-space: nowrap !important;
  transform: none !important; /* 清除之前的 translateX 影响 */
  
  /* 控制位置：通过 relative 定位直接控制右移像素 */
  position: relative !important;
  left: 80px !important; /* 修改这个数值！数值越大，标签越往右移 */
}

/* 3. 给正文区足够的留白，防止标签往右移之后又撞上文字 */
.markdown-source-view.mod-cm6 .cm-sizer {
  margin-left: 60px !important; /* 如果右移后标签挤到了文字，就把这个数值调大 */
}
```
